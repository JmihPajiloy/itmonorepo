# Практическая работа № 3 — логические задачи

Разобраны **задачи 20–22** из выданного списка Кэрролла (страница 3). В № 20 получен модус Celarent (EAE–1) при явно указанном допущении «несчастный = не счастливый». В № 21 получен Barbara (AAA–1). Для № 22 объяснено отсутствие среднего термина и силлогистического вывода.

В отчёте сохранены исходные условия, приведены необходимые преобразования, порядок посылок, термины, фигуры, модусы, круги Эйлера и словесные выводы. Для № 22 дан вердикт с объяснением в пределах 4–400 слов.

## Материалы

- `task.md` — требования пользователя к работе;
- `task.pdf` — присланный список задач, сохранённый без изменений;
- `report.example.pdf` — выданный пример оформления;
- `report.typ`, `report.pdf` — исходник и итоговый отчёт;
- `references.bib` — ссылки на исходные материалы;
- `diagrams/generate.py`, `diagrams/task20.svg`, `diagrams/task21.svg` — исходник и векторные круги Эйлера;
- `check.py`, `verification/logic.json` — семантическая проверка и её результат.

## Проверка и сборка

Нужны Python 3 (без сторонних пакетов), Typst CLI, пакет Typst Gost `modern-g7-32` версии 0.2.0 и шрифт Times New Roman. При первом запуске Typst скачивает пакет, если его ещё нет в локальном кэше.

Из корня репозитория:

```sh
make check SUBJECT=mlta LAB=lab3
make report SUBJECT=mlta LAB=lab3
```

Проверка перебирает заполненность всех областей диаграмм для трёх и четырёх понятий. Проверяются равносильность нормализации посылок и общие заключения задач 20–21. Для № 20 отдельно находится контрпример без допущения о дополнительности понятий. Это проверка формализации; она не выбирает смысл слов автоматически. Разбор отсутствия среднего термина в № 22 дан в отчёте. Проверка также пересоздаёт SVG, а цель `report` собирает PDF.

Задачи 20–22 выбраны по прямому указанию пользователя. Согласование распределения задач с группой и ограничение «не более двух человек на задачу» не проверялись: данных группы нет. Реквизиты автора и группы взяты из инструкций проекта; преподаватель в титульный лист не добавлен, поскольку персональное назначение не подтверждено.
