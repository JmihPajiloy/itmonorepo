# Практическая работа № 1 — виды делений понятия

В работе классифицировано одно неединичное понятие «карты стандартной колоды из 52 карт без джокеров». Выбор отличается от понятия «транспортные средства» в выданном примере отчёта. Первый шаг — дихотомическое деление по цвету масти; второй и третий шаги на ветви красных карт масти червей выполнены по видоизменению признака.

## Состав работы

- `report.typ` — редактируемый исходник отчёта;
- `report.pdf` — собранный отчёт;
- `diagrams/generate.py` — редактируемый генератор схем;
- `diagrams/tree.svg` — древовидная векторная схема;
- `diagrams/circle.svg` — круговая векторная схема;
- `requirements.txt` — закреплённая версия Matplotlib.

SVG сохраняют векторный формат для печати. Генератор Matplotlib проверяет положение и размер подписей перед экспортом.

## Сборка и проверка

Из корня репозитория:

```sh
make check SUBJECT=mlta LAB=lab1
make report SUBJECT=mlta LAB=lab1
```

Для сборки необходимы Python 3 с Matplotlib, Typst CLI с доступом к пакету `modern-g7-32` версии 0.2.0 и системный шрифт Times New Roman. Локальное окружение создаётся в папке работы:

```sh
cd subjects/mlta/lab1
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cd ../../..
make report SUBJECT=mlta LAB=lab1
```

Проверка строит колоду из 52 карт, проверяет непересекаемость и полноту каждого деления, затем заново создаёт схемы и контролирует размещение подписей. Итоговая вёрстка проверяется просмотром PDF.
