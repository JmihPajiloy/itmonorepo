# Лабораторная работа 1 "Защита локальной папки с файлами и веб-странички"

## Задание 1(a): Локальная программа
Разработать программу, запрещающую в текущем (том, котором она находится) каталоге создание, копирование, удаление или переименование файлов с заданными именами (можно использовать маски файлов). Список имен или их шаблонов хранить в файле template.tbl, как текст. Должна быть обеспечена защита этого файла от удаления, несанкционированного просмотра и модификации. При установке программы можно предусмотреть ее отключение с использованием пароля, хранящегося в первой строке файла template.tbl в хешированном виде. Программа должна включать и выключать режим защиты.

На защите лабораторной – демонстрируется работа с выбранными файлами без запуска программы, после запуска программы на блокировку файлов и после отключения блокировки. Платформа любая.

## Задание 1(б): Веб-скрипт
Реализовать скрипт, внедряемый в код HTML-документа, который реализует защиту от копирования в буфер (нет возможности выделять содержимое, копировать в буфер как текст или через скриншот и т.д.) и сохранения всех страниц, вызываемых с текущей. При этом печать этих страниц на бумажный носитель должна быть доступна. Отключение скрипта должно происходить с использованием пароля, хранящегося в теле скрипта в зашифрованном виде.

На защите лабораторной – демонстрируется работа веб-странички с включенной/выключенной защитой от копирования по паролю. В глубину ссылок достаточно ещё двух. Содержимое веб-странички должно содержать текст и графику. Можно отключить/подменять буфер обмена.

## Реализация и запуск

Платформа файловой части — macOS; нужны Python 3 и штатная команда `chflags`. Программа [guard.py](guard.py) работает в каталоге, где лежит сама. Для демонстрации:

```sh
cd subjects/timp/lab1
python3 guard.py init protected.txt archive.txt
python3 guard.py on
python3 guard.py status
python3 guard.py off
```

Пароль вводится без отображения. `init` создаёт `template.tbl`: первая строка содержит хеш PBKDF2, следующие строки — точные имена файлов. Когда защита включена, отсутствующие файлы создаются как пустые заглушки; у них и у таблицы устанавливается флаг `uchg`. Существующие файлы не перезаписываются. После `off` файлы и заглушки остаются, но их можно изменить или удалить. Для показа состояния «до запуска» измените или удалите тестовый файл перед командой `on`. Команда `init` выполняется однократно; повторное включение и выключение используют тот же пароль.

Веб-часть находится в [web/index.html](web/index.html). Запуск локального сервера из `lab1`:

```sh
python3 -m http.server 8000 --directory web
```

Откройте `http://localhost:8000/`. Это три нейтральные страницы с текстом-заполнителем, локальными фотографиями и кнопкой отключения защиты. Источники и лицензии фотографий указаны в [web/vendor/SOURCES.md](web/vendor/SOURCES.md). Демонстрационный пароль: `admin`. Он проверяется расшифровкой AES-GCM маркера через Web Crypto; открытого пароля в скрипте нет. Режим действует на вкладку через `sessionStorage`; состояние, сохранённое до смены пароля, больше не используется. Печать через меню браузера разрешена.

При нажатии ⌘⇧3/4/5/6 страница на восемь секунд размывает содержимое, если браузер передал ей событие клавиатуры. В режиме печати размытие не действует. На macOS системные сочетания часто обрабатываются до страницы, поэтому этот эффект не гарантирует размытие готового снимка.

## Проверка и ограничения

Из корня репозитория: `make check SUBJECT=timp LAB=lab1`. Проверка файловой части работает во временном каталоге и не изменяет демонстрационные файлы. Для неё нужны Python 3 и macOS; веб-проверка дополнительно использует Node.js.

`uchg` обеспечивает запрет для обычных файловых операций без работающего фонового процесса, но владелец может вручную снять флаг. Режим поддерживает точные имена, не маски. Права `0600` ограничивают просмотр `template.tbl` другими пользователями, но процесс того же владельца может читать файл. Браузерный скрипт мешает обычному выделению, копированию и сохранению с клавиатуры; он не способен запретить снимок экрана средствами macOS, просмотр исходного кода, отключение JavaScript или сохранение через инструменты браузера. Блокировка системных снимков для обычной веб-страницы недоступна; флаг `NSWindowSharingNone` в macOS устарел и Apple не рекомендует его для сокрытия содержимого от захвата. FairPlay Streaming защищает видеопоток, а не текст этой страницы. Это демонстрация ограничений защиты на стороне клиента, а не надёжный механизм DRM.

Отчёт: [исходник Typst](report.typ) и [готовый PDF](report.pdf). Для сборки нужен Typst CLI и локальный пакет Typst Gost версии 0.2.0. Команда из корня: `make report SUBJECT=timp LAB=lab1`; она сначала выполняет проверки, затем обновляет PDF. Отчёт подготовлен по запросу пользователя; исходное задание предписывает отправлять его преподавателю после успешной защиты.
