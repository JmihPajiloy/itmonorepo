# Лабораторная работа № 1 «Механизмы защиты Unix-систем»

## Цель

Ознакомление с базовыми модулями защиты Unix-систем.

## Задачи

1. Определить дистрибутив в соответствии с вариантом.
2. Определить, в какой системе расположен защищаемый конечный узел.
3. Определить требования к защите с помощью нормативной базы ФСТЭК России.
4. Выполнить настройку Unix-системы в соответствии с требованиями регулятора.

## Вариант 13

- дистрибутив: Parrot Secure OS (в работе использована Parrot Security Edition);
- тип информационной системы: автоматизированная система класса защищённости 1В.

Задание перенесено из сообщения пользователя. Отдельный исходный файл задания не предоставлен.
