# itmonorepo

Учебный монорепозиторий Ивана Шибаева в Университете ИТМО. Здесь хранятся задания, решения, отчёты и материалы для их воспроизведения по разным дисциплинам. Это набор самостоятельных учебных работ, а не одно приложение: стек и проверки выбираются для каждой работы отдельно.

## Навигация

| Дисциплина | Работы | Содержание |
| --- | --- | --- |
| [ИББД — Информационная безопасность баз данных](subjects/ibbd/README.md) | [Лабораторная № 1](subjects/ibbd/lab1/README.md) | ER-модель, нормализация, SQL и отчёт Typst |

Других дисциплин пока нет. Каталог пополняется по мере добавления работ.

## Устройство репозитория

```text
AGENTS.md                         правила для работающих с проектом агентов
.agents/skills/                   локальные повторяемые процессы
templates/                        общие помощники и титульные листы для отчётов и других работ
subjects/
  <код дисциплины>/
    README.md                     название дисциплины и список работ
    lab<N>/
      README.md                   задание, результаты и команды
      task.docx                   исходное задание, если дано в DOCX
      report.typ / report.pdf     исходник и готовый отчёт
      sql/, diagrams/, ...        исходники конкретной работы
      vendor/                     зависимости конкретной работы, если нужны
      verification/               результаты проверок и просмотра отчёта
```

Новые каталоги создаются по необходимости. Файлы конкретной работы остаются внутри её `lab<N>`, включая результаты сборки. Повторно используемые помощники и титульные листы находятся в `templates/`. Исходное задание, решение и отчёт сохраняются; виртуальные окружения, настройки IDE и временные рендеры исключены через `.gitignore`. PDF отчётов намеренно не исключаются: это готовые материалы для сдачи.

## Команды

Запускать из корня:

```sh
make help
make check SUBJECT=ibbd LAB=lab1
make report SUBJECT=ibbd LAB=lab1
```

`check` выполняет проверки выбранной работы. `report` обновляет диаграмму и собирает PDF. Параметры дисциплины и работы обязательны; общей команды, которая молча запускает все лабораторные, нет.

Для ИББД № 1 проверкам нужны Python 3 и SQLite ≥ 3.37; сборке отчёта — Typst CLI и шрифты Times New Roman, Courier New. Общие помощники для отчётов находятся в [templates](templates).
