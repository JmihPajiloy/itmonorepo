# Информационная безопасность баз данных

Практик: Ярцева Наталия Андреевна

Код дисциплины в репозитории — `ibbd`.

| Работа | Тема | Результат |
| --- | --- | --- |
| [Лабораторная № 1](lab1/README.md) | Инфологическое моделирование БД по методу «сущность–связь» | [Отчёт](lab1/report.pdf), ER-диаграмма, SQL-схема, VIEW и проверки |
| [Лабораторная № 2](lab2/README.md) | Реализация БД в рамках СУБД | [Отчёт](lab2/report.pdf), БД PostgreSQL: таблицы, связи, индексы, данные, VIEW |
| [Лабораторная № 3](lab3/README.md) | Разработка примитивной системы защиты на уровне СУБД | [Отчёт](lab3/report.pdf), журнал изменений, шифрование AES-256, роли и RLS |
| [Лабораторная № 4](lab4/README.md) | Реализация сервиса для взаимодействия с разработанной базой данных | [Отчёт](lab4/report.pdf), веб-интерфейс Flask: вход ролями СУБД, таблицы по привилегиям, отчёты с GROUP BY |
| [Лабораторная № 5](lab5/README.md) | Резервирование БД и восстановление по контрольным точкам | [Отчёт](lab5/report.pdf), pg_basebackup + архив WAL + pg_dump по расписанию, откат к точке восстановления (PITR), анализ через pg_waldump и журнал ЛР3 |

Работы № 2–4 используют общий учебный кластер PostgreSQL, который создаёт [tools/pg.sh](tools/pg.sh); ЛР5 поднимает через него собственный кластер на порту 55433.

Каждая работа хранится в собственной папке `lab<N>` вместе с исходным заданием. Общие правила — в корневом [AGENTS.md](../../AGENTS.md); команды конкретной работы — в её README.
