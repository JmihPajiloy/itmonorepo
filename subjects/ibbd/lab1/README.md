# Лабораторная работа № 1 по ИББД

Шибаев Иван Дмитриевич, N3352.
Тема: «Инфологическое моделирование баз данных по методу „сущность–связь“».
Предметная область: мастерская реставрации музыкальных инструментов (выбрана согласно пункту 1 задания).

## Результаты

- `report.pdf` — готовый отчёт.
- `report.typ` — исходник отчёта, оформленный официальным Typst Gost `modern-g7-32` 0.2.0.
- `references.bib` — библиографические записи, на которые ссылается текст отчёта.
- `task.docx` — исходное задание, без изменений.
- `diagrams/er.svg` — ER-диаграмма; `generate.py` воспроизводит SVG, `er.mmd` содержит связи в Mermaid.
- `sql/01_schema.sql` — 9 таблиц (8 самостоятельных сущностей и ассоциативная таблица), ключи, ограничения и индексы.
- `sql/02_views.sql` — по 2 представления для приёмщика и реставратора.
- `sql/03_demo.sql` — вымышленные демонстрационные данные.
- `lab1.sqlite3` — готовая демонстрационная БД.
- `verify.py` — 19 проверок структуры, ограничений и результатов запросов.
- `verification/` — журнал проверок и CSV четырёх представлений.
- `../../../templates/` — общие помощники и титульные листы; в лабораторной они не дублируются.

## Быстрый запуск

Из корня репозитория:

```sh
make check SUBJECT=ibbd LAB=lab1
make report SUBJECT=ibbd LAB=lab1
```

Из этой папки те же операции выполняются командами `make check` и `make report`. Сборка обновляет SVG по `diagrams/generate.py`, затем PDF. Цель `report` не скачивает зависимости автоматически.

## Проверка БД

Нужны Python 3 и SQLite версии не ниже 3.37 (таблицы STRICT).
Из этой папки:

```sh
python3 verify.py
```

Сценарий собирает БД в памяти и перезаписывает только `lab1.sqlite3`, журнал и CSV в `verification/`. Не используйте демонстрационную БД для собственных рабочих данных. При самостоятельном открытии соединения обязательно выполнить `PRAGMA foreign_keys = ON`.

## Сборка отчёта

Из корня репозитория:

```sh
make report SUBJECT=ibbd LAB=lab1
```

Для сборки нужен Typst CLI (на macOS: `brew install typst`) и шрифты Times New Roman и Courier New. При первой сборке Typst может загрузить пакет `@preview/modern-g7-32:0.2.0` в свой кэш.

В `report.typ` остаются реквизиты и содержание работы. Общий титульный лист импортируется из `/templates/title-page.typ`, а основной текст оформляет стандартный пакет `@preview/modern-g7-32:0.2.0`. Корнем компиляции служит корень репозитория.

## Границы результата

Модель и SQL согласованы; 19 автоматических проверок проходят. Правила перехода статусов и допуска к выдаче описаны как прикладные проверки, а не как реализованные SQL-ограничения. SQLite не обеспечивает серверное разграничение прав: VIEW задают состав информации, доступ к файлу и авторизацию должно контролировать приложение.
