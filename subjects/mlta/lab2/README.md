# Практическая работа № 2 — семантическая сеть

В работе использован фрагмент опубликованной русской народной сказки «Колобок» (№ 36) из собрания А. Н. Афанасьева. По двум эпизодам с зайцем и волком построена семантическая сеть из 10 узлов и 11 связей. Три вида отношений встречаются по два раза. Порядок в отчёте: опубликованный текст с указанием источника, граф, полный список суждений, пояснения.

## Состав работы

- `task.md` — исходное задание;
- `report.example.pdf` — выданный пример отчёта, не источник предметной области;
- `title.pdf` — выданный титульный лист;
- `network.py` — данные сети, содержательные проверки и генератор схемы;
- `network.svg` — векторная семантическая сеть;
- `references.bib` — библиографическая запись опубликованного текста «Колобок»;
- `report.typ` — редактируемый отчёт;
- `report.pdf` — итоговый отчёт.

## Проверка и сборка

Нужны Python 3 и Typst CLI с доступом к пакету `modern-g7-32` версии 0.2.0. Для корректной вёрстки требуется системный шрифт Times New Roman. Дополнительные Python-пакеты не нужны.

Из корня репозитория:

```sh
make check SUBJECT=mlta LAB=lab2
make report SUBJECT=mlta LAB=lab2
```

Проверка контролирует количество и индексацию узлов и отношений, связи между существующими узлами, повторяемость отношений, порядок материалов в отчёте и наличие суждений по фрагменту сказки. Затем она пересоздаёт SVG. Сеть моделирует выбранные отношения из опубликованного фрагмента; программа не извлекает её автоматически из произвольного текста.
