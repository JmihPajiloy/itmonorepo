# Компьютерные сети

Практик: Есипов Дмитрий Андреевич.

В рамках курса выполняются четыре лабораторные работы. Первые три соответствуют заданиям 1, 3 и 4 из [методического пособия](metodichka.pdf) ([источник ИТМО](https://books.ifmo.ru/file/pdf/2275.pdf)). Задание для лабораторной № 4 по VLAN будет выслано позже.

Работы выполняются индивидуально, по своему варианту. Отчёт оформляется по ГОСТ 7.32 и сдаётся в PDF с подписью студента на титульном листе. Для отчётов по дисциплине моноширинный и табличный текст не уменьшаются относительно основного текста; в таблицах не используются внутренние отступы ячеек.

Максимальная оценка — 9 баллов за работу; при сдаче после дедлайна — не более 7 баллов.

## Работы

| Лабораторная | Тема и задание | Дедлайн приёма |
| --- | --- | --- |
| № 1 (`lab1`) | Кодирование данных в телекоммуникационных сетях — задание 1 методички | Сентябрь |
| № 2 (`lab2`) | Анализ трафика компьютерных сетей утилитой Wireshark — задание 3 методички | Октябрь |
| № 3 (`lab3`) | Основы администрирования маршрутизируемых компьютерных сетей — задание 4 методички | Ноябрь |
| № 4 (`lab4`) | VLAN — задание будет выслано позже | Декабрь |

В папках `lab2`–`lab4` пока находятся только примеры отчётов. Они не заменяют исходное задание и не задают вариант работы.

## Уточнения преподавателя к лабораторной № 2

Задание по Wireshark в методичке устарело. Для анализа сайта можно взять ИСУ или ВК; нужно найти страницу, на которой указано ФИО студента. Вместо Skype допускается любая интернет-телефония, например Telegram, ВК, Zoom или Телемост.

По словам преподавателя, при проверке отчёта он смотрит только его объём. На защите спрашивает теорию с предыдущей пары.
