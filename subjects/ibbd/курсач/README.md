# Курсовая работа по ИББД

«Информационная система мастерской реставрации музыкальных инструментов».
Шибаев Иван Дмитриевич и Малышев Григорий Игоревич, группа N3352.

- `task.pdf` — исходное задание.
- `report.pdf` — пояснительная записка с титулом, заданием, графиком, аннотацией и приложениями.
- `report.typ`, `forms.typ`, `details.typ`, `chapters/`, `references.bib` — исходники. Графика, примеры и результаты испытаний берутся из соседних лабораторных.
- Реквизиты руководителя хранятся в `details.typ`, в PDF указано только ФИО. Даты графика и отметка об авторстве цели находятся в `forms.typ`. Три формы подготовлены на двоих в одном комплекте. Перед сдачей сверьте формат общего комплекта и тему в ИСУ, внесите даты этапов и отметку об авторстве цели.

## Сборка

Нужны Typst CLI 0.15, шрифты Times New Roman и Courier New, пакет `@preview/modern-g7-32:0.2.0`. При первой сборке Typst может загрузить пакет в кэш.

Из корня репозитория:

```sh
make report SUBJECT=ibbd LAB=курсач
```

В этой папке достаточно `make report`. Сборка читает сохранённые результаты из ЛР1–5 и не запускает PostgreSQL. Для воспроизведения работы сервиса и восстановления см. инструкции в [ЛР4](../lab4/README.md) и [ЛР5](../lab5/README.md).
