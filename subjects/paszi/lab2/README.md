## Происхождение и ограничения

Собственный стенд Windows запустить не удалось; новая практическая проверка СЗИ не проводилась. Отчёт содержит разбор предоставленных материалов, последовательность настройки и ожидаемые результаты для воспроизведения.

Для Dallas Lock использованы скриншоты из `report.example.pdf`: Матвеев Илья Александрович и Косинский Эдуард Олегович, ИТМО, 2023 год. Для Secret Net в этом примере скриншотов нет, поэтому взяты иллюстрации из `task.pdf`. Источники указаны в примечании во введении и библиографии; страницы для каждого изображения сохранены в `screenshots/sources.json`. Даты, имена и содержимое окон сохранены.

В отчёте разобраны существенные ограничения примера: создание пользователей не доказывает настройку аудита, архивация не является зачисткой архива, список расширений общий, а ошибка проигрывателя со ссылкой на звуковое устройство не подтверждает отказ Dallas Lock. Для Secret Net отдельно отмечено противоречие задания относительно конечной категории Folder4 и описан дополнительный шаг для получения указанной категории.

Версии источников различаются: задание — Dallas Lock 8.0-К и Secret Net 5.1; пример — Dallas Lock 8.0-С; дополнительные руководства — Dallas Lock 8.0.565.2, Secret Net 6 и Secret Net Studio. Эти различия отмечены в отчёте.

## Проверка и сборка

Требуются Python 3.9+ для проверки и CLI Typst 0.14+ с пакетом `modern-g7-32:0.2.0`. При первой сборке Typst загружает пакет, если он отсутствует в кэше. Титульный лист использует общий шаблон репозитория `templates/title-page.typ`.

Из корня репозитория:

```sh
make check SUBJECT=paszi LAB=lab2
make report SUBJECT=paszi LAB=lab2
```

`check` проверяет SHA-256 исходных PDF и извлечённых изображений, происхождение всех иллюстраций отчёта, ссылки на рисунки, таблицы и библиографию. Это проверка материалов отчёта, а не работоспособности СЗИ на Windows. `report` выполняет `check` и собирает итоговый `report.pdf`.

На macOS CLI Typst можно установить командой `brew install typst`. Изображения уже сохранены, поэтому для обычной сборки дополнительные Python-пакеты не нужны.

Для повторного извлечения скриншотов:

```sh
cd subjects/paszi/lab2
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-build.txt
make screenshots
make report
```

Извлечение использует PyMuPDF 1.28.2 и сохраняет исходные встроенные изображения PDF. Небольшие служебные значки менее 100 пикселей по любой стороне пропускаются. Проверка вёрстки выполнялась рендерингом готового PDF; собственных журналов Dallas Lock и Secret Net в этой работе нет.
