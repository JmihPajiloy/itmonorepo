# Лабораторная работа № 1 — кодирование данных

Выполнено задание 1 из методического пособия: физическое кодирование сообщения «Шибаев И.Д.» пятью методами, кодирование 4B/5B, скремблирование, расчёт частотных характеристик и сравнительный анализ.

## Состав работы

- `report.typ`, `report.pdf` — исходник и готовый отчёт;
- `references.bib` — библиографические записи, на которые ссылается текст отчёта;
- `../../../templates/title-page.typ` — общий минимальный титульный лист; принимает дисциплину, номер работы, тему, ФИО студента и ФИО преподавателя. Необязательный параметр `group` нужен только для работ другой учебной группы;
- `generate.py` — воспроизводимые преобразования, проверки и генерация диаграмм;
- `generated/results.json` — точные результаты вычислений;
- `generated/*.svg` — временные диаграммы первых четырёх байт;
- `report.example.pdf` — предоставленный пример прошлого года, не являющийся результатом этой работы.

## Воспроизведение

Из корня репозитория:

```sh
make -C subjects/comp-seti/lab1 setup
make check SUBJECT=comp-seti LAB=lab1
make report SUBJECT=comp-seti LAB=lab1
```

Цель `setup` создаёт локальное окружение лабораторной и устанавливает фиксированную версию Matplotlib для векторных временных диаграмм. Для сборки отчёта требуется Typst CLI (на macOS: `brew install typst`). Расчёт использует кодировку Windows-1251 из таблицы методички и скорость передачи 1 Гбит/с. Частотные значения являются оценками основной гармоники по длительности серий и переходов, как предписано методикой, а не результатом измерения аналогового спектра.
