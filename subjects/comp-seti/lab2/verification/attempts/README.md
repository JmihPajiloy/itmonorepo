# Предварительные попытки

Эти файлы сохранены для прозрачности проверки и не подтверждают успешные опыты, описанные в отчёте.

- telegram-text.pcap и его JSON — предварительный захват 124 пакетов сетевых заголовков. Отправка сообщения и ответ не подтверждены. После выбора Телемоста Telegram больше не использовался; старый сценарий сохранён как исторический материал.
- telemost-audio-tunnel-only.pcapng — 32 служебных пакета STUN из первоначальной попытки записи только VPN-туннеля. Успешный самостоятельный аудиосеанс находится в ../../captures/telemost-audio.pcapng.

Остальные файлы неудачных попыток при их наличии следует оценивать по сопровождающим JSON и журналам, а не по предполагаемому этапу в имени файла.

- telemost-text-empty.pcapng и JSON — первоначальный пустой захват с неверно выбранным транспортом. Успешный повторный опыт: ../../captures/telemost-text.pcapng; 59 пакетов выбранного WebSocket уведомлений.
