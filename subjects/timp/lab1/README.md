# Лабораторная работа 1 "Защита локальной папки с файлами и веб-странички"

## Задание 1(a): Локальная программа
Разработать программу, запрещающую в текущем (том, котором она находится) каталоге создание, копирование, удаление или переименование файлов с заданными именами (можно использовать маски файлов). Список имен или их шаблонов хранить в файле template.tbl, как текст. Должна быть обеспечена защита этого файла от удаления, несанкционированного просмотра и модификации. При установке программы можно предусмотреть ее отключение с использованием пароля, хранящегося в первой строке файла template.tbl в хешированном виде. Программа должна включать и выключать режим защиты.

На защите лабораторной – демонстрируется работа с выбранными файлами без запуска программы, после запуска программы на блокировку файлов и после отключения блокировки. Платформа любая.

## Задание 1(б): Веб-скрипт
Реализовать скрипт, внедряемый в код HTML-документа, который реализует защиту от копирования в буфер (нет возможности выделять содержимое, копировать в буфер как текст или через скриншот и т.д.) и сохранения всех страниц, вызываемых с текущей. При этом печать этих страниц на бумажный носитель должна быть доступна. Отключение скрипта должно происходить с использованием пароля, хранящегося в теле скрипта в зашифрованном виде.

На защите лабораторной – демонстрируется работа веб-странички с включенной/выключенной защитой от копирования по паролю. В глубину ссылок достаточно ещё двух. Содержимое веб-странички должно содержать текст и графику. Можно отключить/подменять буфер обмена.

## Что сделано

- `guard.py` — включение, просмотр состояния и отключение защиты файлов на macOS; эти команды требуют пароль. Его хеш PBKDF2 хранится в первой строке `template.tbl`.
- `web/index.html`, `web/page2.html`, `web/page3.html` — три связанные страницы об устройстве компьютера. Оформление простое: белый фон, стандартные ссылки и кнопки, один небольшой CSS-файл.
- `web/images/` — собственные SVG-схемы компьютера, процессора и памяти. Внешние изображения, библиотеки и сборщик не нужны.
- `web/protect.js` — ограничение выделения, копирования, перетаскивания, контекстного меню и горячих клавиш сохранения. Отключение по паролю; печать разрешена.
- [Отчёт PDF](report.pdf) и [исходник Typst](report.typ).

## Запуск сайта

Из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory subjects/timp/lab1/web
```

Откройте <http://localhost:8000/>. Демонстрационный пароль отключения защиты: **admin**. Для Web Crypto нужен localhost либо HTTPS; открывать страницы лучше через сервер, а не двойным щелчком по HTML.

1. Попробуйте выделить текст, скопировать его, вызвать контекстное меню, перетащить изображение и сохранить страницу сочетанием Ctrl+S или ⌘S.
2. Перейдите по ссылке на вторую, затем на третью страницу — ограничения действуют на каждой.
3. Нажмите «Отключить по паролю». Неверный пароль оставляет защиту включённой; `admin` разрешает копирование.
4. Перейдите между страницами: выбранный режим сохраняется в пределах вкладки. Кнопка «Включить защиту» снова включает ограничения.
5. Откройте печать через меню браузера или Ctrl+P / ⌘P. Текст и рисунок доступны для печати, элементы управления скрыты.

Пароль проверяется расшифровкой маркера AES-GCM ключом, полученным через PBKDF2. Открытой строки пароля в скрипте нет. Это учебная проверка на стороне клиента, её можно обойти.

## Запуск файловой части

Нужны macOS, Python 3 и штатная команда `chflags`. Сторонних Python-пакетов нет. Программа действует в каталоге, где лежит сама. Для демонстрации используйте отдельный временный каталог:

```sh
demo_dir=$(mktemp -d /tmp/timp-demo.XXXXXX)
cp subjects/timp/lab1/guard.py "$demo_dir/"
cd "$demo_dir"
printf 'Исходный текст\n' > protected.txt
python3 guard.py init protected.txt archive.txt
# До защиты запись работает:
printf 'До защиты\n' >> protected.txt
python3 guard.py on
python3 guard.py status
# При защите следующие операции должны завершиться ошибкой:
printf 'Изменение\n' >> protected.txt
cp guard.py protected.txt
mv protected.txt renamed.txt
rm protected.txt
rm template.tbl
python3 guard.py off
# После отключения запись и переименование снова работают:
printf 'После защиты\n' >> protected.txt
mv protected.txt renamed.txt
```

Пароль задаётся при `init`, затем вводится при `on`, `status` и `off` без отображения. Повторная инициализация не нужна. Отсутствующие файлы создаются пустыми, чтобы занять защищаемые имена; существующие сохраняют содержимое. Флаг `uchg` запрещает обычные операции изменения, удаления и переименования, в том числе для `template.tbl`. После отключения файлы остаются на месте. Защита сохраняется после завершения программы, поэтому для снятия ограничений выполните `off`.

## Проверки и сборка отчёта

Из корня репозитория:

```sh
make check SUBJECT=timp LAB=lab1
make report SUBJECT=timp LAB=lab1
```

Для проверок нужны macOS, Python 3 и Node.js с Web Crypto (например, Node.js 22 или новее). Файловые проверки запускаются во временном каталоге: проверяются операции до включения, во время защиты и после отключения, а также пароль и сохранность таблицы. Веб-проверки проверяют наличие страниц и ресурсов, цепочку ссылок, пароль, переключение режима, события копирования и размытие при удержании Cmd + Shift и его снятие при отпускании клавиш. События в Node.js синтетические и не заменяют проверку реальных системных клавиш.

Для отчёта дополнительно нужен Typst CLI с пакетом `@preview/modern-g7-32:0.2.0` (Typst Gost). Если пакета нет в локальном кеше, первая сборка требует доступа к реестру Typst. Цель `report` сначала запускает проверки, затем собирает `report.pdf`.

## Ограничения

Точные имена поддерживаются, маски — нет. Права `0600` ограничивают чтение `template.tbl` другими пользователями, но владелец может читать таблицу и вручную снимать `uchg`. Чтение и копирование содержимого защищённого файла в другой каталог не запрещены; блокируется копирование поверх защищённого имени.

Обычная веб-страница не может гарантированно запретить системный снимок экрана, сохранение через меню браузера, просмотр исходников или отключение JavaScript. При включённой защите скрипт размывает содержимое, пока одновременно удерживаются Cmd + Shift. Отпускание любой из этих клавиш снимает размытие. При смене окна или скрытии вкладки эффект сбрасывается, чтобы он не оставался включённым из-за пропущенного события отпускания. Реакция зависит от доставки клавиатурных событий браузеру. Печать не размывается. Эти пункты исходного задания реализованы только в пределах возможностей браузерного скрипта, полноценная защита от извлечения содержимого не обеспечивается.
